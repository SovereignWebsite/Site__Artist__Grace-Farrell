Use this site with AI

This site is written for people and for AI agents. Point your agent at llms.txt and tell it who you are; it will find the right instructions.

If you are visiting

Paste this into any assistant that can read web pages:

Read https://grace-farrell.artist.sovereignweb.site/llms.txt and follow the instructions for a visitor.
Then answer my questions about Grace Farrell, with a link for each point,
and say plainly when the site does not say something.

If you own this site

Give your agent write access to the repository (see Start here), then tell it:

Read https://grace-farrell.artist.sovereignweb.site/llms.txt and follow the instructions for the owner.
I want to change: [describe the change].
